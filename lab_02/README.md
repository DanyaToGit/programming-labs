Цель лабораторной работы
Изучение синтаксиса и практических возможностей условных операторов (if-elif-else), циклических конструкций (while, for..in) и пользовательских функций (def) в языке Python. Приобретение навыков декомпозиции алгоритмов управления, передачи аргументов и возврата результатов вычислений.
Краткие теоретические сведения
Условный оператор if-elif-else: Используется для проверки логических условий и ветвления алгоритма. 
Конструкция elif позволяет связывать несколько последовательных проверок без добавления лишней вложенности отступов. 
Блок else выполняется, если ни одно из условий не подтвердилось. Обязательным синтаксическим правилом является использование двоеточия(:) и строгое соблюдение отступов (4 пробела).
Цикл while: выполняет блок выражений до тех пор, пока проверяемое условие истинно (True). Для экстренного выхода из цикла применяется оператор break, а для перехода к следующей итерации — continue. При естественном завершении цикла выполняются команды из необязательного блока else.
Цикл for..in и функция range(): осуществляет перебор элементов последовательности (списков, строк или диапазонов). Встроенная функция range(start, stop, step) генерирует арифметическую прогрессию чисел, не включая верхнюю границу stop.
Пользовательские функции (def): представляют собой многократно используемые блоки кода с собственным именем. Функция объявляется с помощью ключевого слова def, принимает параметры и возвращает результаты вычислений оператором return. Строки документации docstrings (в тройных кавычках) размещаются сразу после заголовка функции для описания ее назначения.

Задание (Вариант 11)
Нейтрализация стоков. Написать функцию neutralize_ph(start_ph), моделирующую в цикле добавление щелочи (+0.5 pH) при pH < 6.5 или кислоты (-0.5 pH) при pH > 7.5. Цикл останавливается при попадании pH в диапазон [6.5; 7.5]. Функция возвращает число доз.
Код для выполнения задания
```bash
def get_start_ph():
    while True:  
        user_input = input("Введите начальное значение pH (от 0 до 14): ")
        user_input = user_input.replace(",", ".")
        check = user_input.replace(".", "", 1)
        if check.isdigit() == False:
            print("Ошибка: нужно ввести число, например 4.2 или 9.\n")
            continue
        ph = float(user_input)  
        if ph < 0 or ph > 14:
            print("Ошибка: pH должен быть в диапазоне от 0 до 14.\n")
            continue
        return ph
def neutralize_ph(start_ph):
    ph = start_ph
    doses = 0
    while ph < 6.5 or ph > 7.5:
        if ph < 6.5:
            ph += 0.5
            print(f"Добавлена щёлочь. Текущий pH = {ph:.1f}")
        else:
            ph -= 0.5
            print(f"Добавлена кислота. Текущий pH = {ph:.1f}")
        doses += 1 
    return doses
def main():
    print("=== Программа нейтрализации раствора ===\n")
    start_ph = get_start_ph()
    print(f"\nНачальный pH = {start_ph}\n")
    doses = neutralize_ph(start_ph)    
    print(f"\nИтог: pH доведён до нейтрального диапазона [6.5; 7.5].")
    print(f"Количество добавленных доз: {doses}")
if __name__ == "__main__":
    main()
```
