Краткие теоретические сведения
Язык Python является интерпретируемым. При первом запуске код транслируется в промежуточный байт-код и выполняется виртуальной машиной (CPython). Переменные представляют собой ссылки (имена), связанные с объектами в динамической памяти. Отступы (ровно 4 пробела) обязательны и служат для группировки блоков кода. Форматированные строковые литералы (f-строки) позволяют удобно вставлять выражения в строки. Например, выражение f'{pi:.3f}' форматирует вещественное число с точностью до трех знаков после запятой.
Задание на лабораторную работу
Напишите скрипт, вычисляющий физическую величину по формуле. Все переменные должны быть динамически привязаны к значениям. Вывод результата осуществить с округлением вещественной части до 4 знаков после запятой. Расход жидкости в трубе: Q = S * v (S = pi * d^2 / 4) pi = 3.14159, d = 0.15, v = 2.4
Код для решения задания:
pi = 3.14159
d = float(input("Введите диаметр (d): "))
v = float(input("Введите высоту (v): "))
s = (pi * (d**2)) / 4
Q = s * v
print("-" * 20)
print(f"Результаты расчетов:")
print(f"Площадь (s): {round(s, 4)}")
print(f"Объем (Q):   {round(Q, 4)}")
print("-" * 20)
Описание элементов кода
```bash
•	input() всегда возвращает строку.
•	float() превращает строку в число с плавающей точкой.
•	print() выводит информацию на экран.
•	f"..." — это f-строка, удобный способ вставить значения переменных в текст.
•	{} внутри f-строки — место подстановки переменной или выражения.
•	round(число, количество_знаков) округляет число.
•	** — возведение в степень.
•	* — умножение, а для строк — повторение.
•	/ — деление, результат всегда float.
•	Скобки в формулах управляют порядком действий.
•	Программа линейная: команды выполняются сверху вниз.
```
